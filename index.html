Kết nối trợ lý (chỉ làm 1 lần)

Trợ lý là chương trình nhỏ chạy ngầm trên máy này để quét và sửa. Cài một lần; lần sau mở trang là tự kết nối.

  1. Tải trợ lý
  2. Chạy file vừa tải, chọn Yes
    Trợ lý chạy ngầm và tự mở lại trang này với mã đã điền.
  3. Chưa tự kết nối?
Trợ lý bị chặn khi tải hoặc cài? Xem cách xử lý
  1. “These files can’t be opened – Your Internet security settings prevented…”: Windows đánh dấu file tải từ Internet và chính sách bảo mật chặn mở. Cách nhanh nhất: bấm “Sao chép lệnh cài” bên dưới rồi dán vào PowerShell (Admin) – không cần mở file. Hoặc bấm “Sao chép lệnh gỡ chặn”, dán vào PowerShell, rồi chạy lại file.
  2. Trình duyệt chặn tải file .bat: ở thanh tải xuống chọn “Keep / Giữ” (Chrome: mũi tên ▾ → Keep; Edge: dấu … → Keep).
  3. “Windows protected your PC” (SmartScreen): bấm “More info” → “Run anyway”; hoặc chuột phải file → Properties → tick “Unblock” → OK.
  4. Windows Security/diệt virus chặn hoặc xóa file: trợ lý chạy ngầm và nhận lệnh từ trang web nên dễ bị nghi ngờ. Nếu bạn tin tưởng: Windows Security → Virus & threat protection → Protection history → Restore, rồi thêm thư mục C:\ProgramData\BaoTri vào Exclusions. Máy của cơ quan: hỏi bộ phận IT.
  5. Vẫn không tải/chạy được file: dùng cách dán lệnh bên dưới (không cần tải file).

Cách dán: bấm Start, gõ PowerShell, chuột phải → Run as administrator; bấm chuột phải vào cửa sổ để dán; nhấn Enter. Với bản .txt: mở bằng Notepad, Ctrl+A, Ctrl+C rồi dán như trên.

Hướng dẫn nối máy in Wi-Fi
    
 
  1. Trên màn hình máy in: Cài đặt/Network → Wi-Fi → chọn đúng Wi-Fi văn phòng → nhập mật khẩu (hoặc bấm WPS trên router rồi WPS trên máy in).
    2. 
 
  2. Máy in và máy tính phải cùng Wi-Fi/dải mạng. Không dùng Wi-Fi “khách/guest” (thường bị cô lập).
    3. 
 
  3. Bấm Dò máy in bên dưới → chọn máy in tìm thấy → Cài đặt. Hoặc in trang “Network configuration” từ máy in để lấy IP.
    4. 
 
  4. Máy in chưa vào được Wi-Fi? Bật Wi-Fi Direct trên máy in, bấm Tìm máy in Wi-Fi Direct → kết nối → dò máy in; hoặc dùng cáp USB để cấu hình Wi-Fi lần đầu.
    5. 
 
  5. Nên đặt IP cố định (hoặc “DHCP reservation” trên router) cho máy in để IP không đổi và hết báo Offline.

Cài đặt AI (dùng key miễn phí)
Dán key của một hoặc nhiều nhà cung cấp. Công cụ tự chọn model phù hợp với key và tự đổi sang model/nhà cung cấp khác khi gặp lỗi (hết hạn mức, model bị gỡ…). Câu hỏi và tóm tắt máy được gửi tới nhà cung cấp bạn chọn.
