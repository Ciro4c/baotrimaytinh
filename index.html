Rescue USB Hub

Chọn gói có sẵn hoặc tự chọn từng mục, bấm một nút là có ngay bộ cài. Mở file này trực tiếp (bấm đúp) hoặc qua web đều dùng được, không cần server.

Gói đề xuất (1 click)

Bấm vào gói sẽ tự chọn đúng mục rồi tải ngay bộ cài khớp với hệ điều hành máy bạn đang dùng (...). Chạy xong là có USB boot.

Tự chọn

Máy chủ chứa ISO (tùy chọn)

Bản mã nguồn mở sẽ tải từ URL/tên-file.iso trên server của bạn nếu có. Windows luôn tải chính thức từ Microsoft; vài công cụ cứu hộ chuyên dụng phải tải tay từ trang gốc (trang sẽ ghi rõ).

Dành dung lượng USB làm ổ lưu trữ (tùy chọn)

USB còn dư chỗ sau khi chứa ISO? Dành riêng một phần làm ổ lưu trữ bình thường (chép file qua lại), phần này tách biệt với vùng boot nên không bị Ventoy ghi đè.

Tạo bộ cài thủ công

0 mục đã chọn, khoảng 0 GB. Cần USB từ 16 GB, nên 32 GB trở lên nếu có Windows, cộng thêm phần lưu trữ nếu chọn ở trên.

Windows:  bấm đúp vào rescue-setup.bat (Windows sẽ hỏi quyền Admin, bấm Yes là chạy)
Linux:    sudo bash rescue-usb.sh install /dev/sdX
Bộ cài sẽ XÓA SẠCH USB và yêu cầu gõ lại đúng tên ổ để xác nhận — đây là bước an toàn bắt buộc, không tự động hóa được vì có thể chọn nhầm ổ.

Vì sao cắm USB vào máy cứ vào thẳng Windows?

USB không tự "giành quyền" boot trước ổ cứng. Máy tính luôn boot theo thứ tự đặt trong BIOS/UEFI, mặc định thường là ổ cứng trước. Cắm USB vào mà không đổi gì thì máy bỏ qua USB và vào thẳng Windows như cũ — đây là hành vi bình thường, không phải USB hỏng.

Cách vào đúng USB mỗi lần cần cứu hộ (không cần đổi cấu hình lâu dài):

  1. Cắm USB trực tiếp vào cổng máy (tránh qua hub).
  2. Khởi động lại máy, bấm liên tục phím boot menu ngay khi vừa bật nguồn (xem bảng bên dưới theo hãng máy).
  3. Một danh sách ổ đĩa hiện ra — chọn tên USB (thường ghi "Ventoy" hoặc tên hãng USB).
  4. Nếu không thấy USB trong danh sách: vào BIOS (thường phím F2/Del), tắt Secure Boot và Fast Boot/Fast Startup, lưu lại rồi thử lại bước 2.

Nếu muốn USB luôn boot trước vĩnh viễn, vào BIOS và đổi thứ tự boot (Boot Order) đưa USB lên đầu — nhưng cách bấm phím boot menu mỗi lần an toàn hơn vì không ảnh hưởng việc khởi động bình thường sau này.

  [Enter] khoi dong muc chon   [F1] tro giup   [F5] che do cong cu

Trong menu, chọn ISO nào thì máy boot y như nhét đĩa gốc đó vào — tự vào trình cài Windows, trình cài Linux, hoặc môi trường cứu hộ tương ứng, không cần thao tác thêm. Windows cần key bản quyền để kích hoạt. Phiên bản/link trong danh mục là mẫu, hãy cập nhật và điền SHA256 trước khi dùng thật.
